\# Admin Panel  

\### Tournament Creation, Division Management, Overrides, Scheduling Control, and Real‑Time Operations



This document defines the Admin Panel used by the Tournament Planner System.  

It describes all administrative controls, workflows, override capabilities, and real‑time management tools available to tournament directors.



This file is part of the modular documentation set referenced in 00\_MASTER\_INDEX.md.



\---



\# 1. Purpose



The Admin Panel is the command center for tournament directors. It provides tools for:



\- Creating tournaments  

\- Managing divisions  

\- Entering teams  

\- Editing seeds  

\- Generating pools  

\- Generating schedules  

\- Managing venues and courts  

\- Overriding match results  

\- Overriding schedules  

\- Managing officials and work teams  

\- Adjusting match formats  

\- Locking and unlocking matches  

\- Monitoring real‑time progress  

\- Printing and exporting documents  



The Admin Panel must be fast, reliable, and optimized for tournament‑day pressure.



\---



\# 2. Core Sections of the Admin Panel



The Admin Panel contains the following major sections:



1\. Tournament Dashboard  

2\. Division Manager  

3\. Team Manager  

4\. Pool Manager  

5\. Bracket Manager  

6\. Schedule Manager  

7\. Venue \& Court Manager  

8\. Officiating \& Work Manager  

9\. Match Control Center  

10\. Printing \& Export Center  

11\. Settings \& Overrides  



Each section is described below.



\---



\# 3. Tournament Dashboard



The dashboard provides:



\- High‑level tournament overview  

\- Division status indicators  

\- Match progress indicators  

\- Alerts and warnings  

\- Quick links to critical actions  



Dashboard alerts include:



\- Behind schedule  

\- Court unavailable  

\- Missing officials  

\- Missing work teams  

\- Conflicting assignments  

\- Overlapping matches  



\---



\# 4. Division Manager



The Division Manager allows admins to:



\- Create divisions  

\- Rename divisions  

\- Assign teams to divisions  

\- Configure division formats  

\- Configure match formats  

\- Configure work assignment rules  

\- Configure officiating requirements  

\- Generate pools  

\- Generate brackets  



Division status indicators show:



\- Pools generated  

\- Pool play in progress  

\- Brackets generated  

\- Bracket play in progress  

\- Division completed  



\---



\# 5. Team Manager



The Team Manager allows admins to:



\- Add teams  

\- Edit team names  

\- Edit club names  

\- Edit coach names  

\- Assign seeds  

\- Move teams between divisions  

\- Remove teams  

\- Add metadata (region, notes, etc.)  



Team lists may be sorted by:



\- Seed  

\- Name  

\- Club  

\- Region  



\---



\# 6. Pool Manager



The Pool Manager allows admins to:



\- Generate pools  

\- Edit pool assignments  

\- Edit pool names  

\- Edit pool order  

\- View pool standings  

\- Override pool standings  

\- Override tiebreakers  

\- Regenerate pools (if allowed)  



Pool Manager also displays:



\- Pool match list  

\- Court assignments  

\- Work assignments  

\- Standings table  



\---



\# 7. Bracket Manager



The Bracket Manager allows admins to:



\- Generate brackets  

\- Edit bracket structure  

\- Edit seeds  

\- Move teams manually  

\- Override advancement  

\- Add or remove consolation rounds  

\- Add or remove placement rounds  

\- Enable or disable reseeding  

\- Assign venues for bracket rounds  



Bracket Manager displays:



\- Championship side  

\- Consolation side  

\- Placement rounds  

\- Advancement paths  

\- Match numbers  



\---



\# 8. Schedule Manager



The Schedule Manager allows admins to:



\- View all matches  

\- Filter by division, venue, court, or team  

\- Move matches between courts  

\- Move matches between venues  

\- Change match times  

\- Change match formats  

\- Add or remove time slots  

\- Override scheduling conflicts  

\- Lock or unlock matches  



Schedule Manager highlights:



\- Back‑to‑back conflicts  

\- Venue travel conflicts  

\- Work team conflicts  

\- Official conflicts  

\- Court availability issues  



\---



\# 9. Venue \& Court Manager



The Venue \& Court Manager allows admins to:



\- Add venues  

\- Add courts  

\- Edit court labels  

\- Edit availability windows  

\- Mark courts unavailable  

\- Assign pools to venues  

\- Assign brackets to venues  



Venue Manager displays:



\- Court availability  

\- Venue‑specific schedules  

\- Travel‑time rules  



\---



\# 10. Officiating \& Work Manager



This section allows admins to:



\- Assign officials  

\- Assign work teams  

\- Override assignments  

\- Edit officiating roles  

\- Edit work assignment rules  

\- View official schedules  

\- View team work schedules  



Conflict indicators include:



\- Official double‑booked  

\- Team working while playing  

\- Team working at wrong venue  

\- Missing required roles  



\---



\# 11. Match Control Center



The Match Control Center is used during live tournament operations.



Admins can:



\- Enter scores  

\- Edit set scores  

\- Mark matches in progress  

\- Mark matches completed  

\- Override match results  

\- Reopen matches  

\- Lock matches  

\- Apply time‑limit behavior  

\- Apply forfeits  

\- Apply retirements  



Match Control Center displays:



\- Real‑time match status  

\- Court status  

\- Officials assigned  

\- Work teams assigned  

\- Next matches on deck  



\---



\# 12. Printing \& Export Center



Admins can generate:



\- Pool sheets  

\- Bracket sheets  

\- Court schedules  

\- Team schedules  

\- Work schedules  

\- Officiating schedules  

\- Venue packs  

\- Final results  



Admins can also export:



\- Pools  

\- Brackets  

\- Matches  

\- Standings  

\- Assignments  



Supported formats include:



\- PDF  

\- CSV  

\- JSON  

\- XML  



\---



\# 13. Settings \& Overrides



Admins may override:



\- Match formats  

\- Time limits  

\- Caps  

\- Win‑by‑two rules  

\- Work assignment rules  

\- Officiating rules  

\- Standings  

\- Seeds  

\- Bracket advancement  

\- Court availability  

\- Venue availability  

\- Travel‑time rules  



Overrides must be logged.



\---



\# 14. Logging \& Audit Trail



The Admin Panel must maintain a complete audit trail of:



\- Score changes  

\- Match result overrides  

\- Schedule changes  

\- Court changes  

\- Venue changes  

\- Work assignment overrides  

\- Official assignment overrides  

\- Standings overrides  

\- Bracket overrides  



Audit logs must include:



\- Timestamp  

\- Admin user  

\- Action performed  

\- Before and after values  



\---



\# 15. Real‑Time Monitoring Tools



The Admin Panel includes:



\- Live court map  

\- Live match list  

\- Live bracket view  

\- Live pool standings  

\- Live team schedule updates  

\- Live officiating and work assignment updates  



These tools allow directors to react quickly to delays or issues.
